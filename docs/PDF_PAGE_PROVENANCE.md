# JAFAR 2.1 — физические страницы PDF и достоверность цитирования

При локальном импорте юридических документов источник ссылки определяется
следующим образом.

## Новые PDF

Нативный разбор PDF через pypdf читает текст **по каждой физической странице**
и сохраняет её номер в структуре ParsedPage. Семантическая разбивка на
фрагменты выполняется отдельно для каждой страницы. Фрагменты разных страниц
не объединяются. Пустые страницы не получают искусственного текста. В
документе сохраняются технические метаданные page_kind=pdf_physical.

Номер является **номером физической страницы PDF** (с единицы), а не номером
листа уголовного дела или удостоверенной страницей бумажного оригинала.
Верный текстовый слой не доказывает подлинность документа. Сканированные
страницы без текстового слоя требуют отдельной OCR-обработки и визуальной
сверки; их нельзя выдавать за распознанные.

## TXT / DOCX / сторонние парсеры PDF

Если локальный парсер не умеет подтвердить физическую страницу, каждому
фрагменту назначается source_page=0 (unknown). В интерфейсе и при копировании
справки показывается «страница не установлена», а не искусственное «стр. 1».

Внешний провайдер разбора PDF не получает достоверных метаданных страниц
только на основании плоского текста. Такие документы остаются unknown до
появления проверенного адаптера с разметкой реальных страниц.

## Старые записи

Ранее импортированным документам page_kind не присваивался. Существовавший
source_page=1 мог быть заглушкой. Поэтому при чтении старого корпуса API
возвращает page_provenance=unknown, даже если технический идентификатор
содержит page:1. Никакой автоматической подмены старых ссылок нет.

Для получения физической разметки PDF в бета-версии необходимо заново
импортировать исходный PDF в выбранное дело и затем сверить полученные
ссылки. Ранее созданные файлы, заметки, черновики и другие материалы
автоматически не удаляются.

## Защитные требования

- Page provenance включается только для NativeDocumentParser PDF.
- Страницы обязаны иметь возрастающие последовательные номера 1..N.
- Собранный текст по страницам должен соответствовать извлечённому тексту.
  При несоответствии импорт блокируется.
- Код не обращается к облачным сервисам для получения номеров страниц.
- Нельзя считать номер физической страницы листом дела без отдельного
  подтверждения в материалах.
- При обработке нескольких документов продолжает действовать изоляция Matter.
- Проверять на синтетических многостраничных PDF и TXT/DOCX с неизвестным
  источником страниц.

## Готовность

Эта доработка распространяется на **новый локальный импорт**. Она не является
универсальной OCR-системой, не распознаёт таблицы и изображения без текстового
слоя и не удостоверяет процессуальные реквизиты документов.
