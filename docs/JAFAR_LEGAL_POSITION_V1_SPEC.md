# JAFAR Legal Position v1 (design contract)

This is a proposed, documentation-only contract. It does not add API or schema.

| Section | Status | Current evidence |
|---|---|---|
| Case summary | EXISTING | `Matter` model |
| Established facts | DERIVED | stored document/event analysis structures |
| Allegations / opponent position | DERIVED | `Matter.opposing_party`, provenance-aware analysis |
| Defense position | PROPOSED | no canonical persisted position model |
| Supporting evidence | DERIVED | document/chunk relationships |
| Contradictions | PROPOSED | reasoning helpers exist, no workspace contract |
| Legal norms / case law | PROPOSED | no dedicated persisted model |
| Risks | DERIVED | legal analysis risk levels, not a matter workspace |
| Evidence gaps | DERIVED | analysis `missing_information` |
| Sources / provenance | EXISTING | event/document source fields; page provenance only in pipeline data |
| Human review status | PROPOSED | approval concepts exist, no unified position state |

Future workflow must remain: source → AI analysis → draft position → lawyer review → approved position. AI output is advisory and never an automatic filing or outbound action.
